# Экспертная система оценки стоимости веб-проектов

Прототип экспертной системы, разработанный в рамках производственной практики (технологической) в Университете «Синергия» (synergy.ru). Система автоматизирует процесс предварительной оценки стоимости и сроков разработки IT- и веб-проектов.

## Возможности

- Пошаговый опросник (6 шагов)
- Оценка стоимости и сроков на основе базы знаний
- Механизм логического вывода (правила «ЕСЛИ-ТО»)
- Объяснение принятия решений (какие правила сработали и почему)
- Рекомендация по составу команды
- Детализация расчёта

## Параметры оценки

- Тип проекта (корпоративный сайт, интернет-магазин, CRM, портал, мобильное приложение)
- Уровень дизайна (шаблонный, стандартный, индивидуальный, премиум)
- Объём проекта (количество страниц/экранов)
- Техническая сложность
- Мобильная версия (адаптивная, PWA, нативная)
- Интеграции (платёжные системы, CRM, ERP/1С, API, уведомления, аналитика)
- Хостинг (виртуальный, VPS, облако, выделенный сервер)

## Технологии

- **Python 3.9+**
- **Flask** — веб-фреймворк
- HTML/CSS/JavaScript — интерфейс пользователя

## Установка и запуск

### 1. Убедитесь что Python установлен

```bash
python3 --version
```

Если Python не установлен, скачайте с https://www.python.org/downloads/

### 2. Установите Flask

```bash
pip3 install flask
```

### 3. Запустите приложение

```bash
cd expert-system
python3 app.py
```

### 4. Откройте в браузере

```
http://localhost:5001
```

## Структура проекта

```
expert-system/
├── app.py              # Веб-приложение (Flask + интерфейс)
├── knowledge_base.py   # База знаний и механизм логического вывода
└── README.md           # Документация
```

### knowledge_base.py

Содержит:
- **Факты** — параметры проектов (типы, дизайн, сложность, интеграции, хостинг) с базовыми стоимостями и множителями
- **Правила** — 6 правил вида «ЕСЛИ условие ТО действие» с объяснениями:
  - R1: Корректировка CRM для enterprise
  - R2: Скидка на лендинг с шаблоном
  - R3: Увеличение при множественных интеграциях
  - R4: Премиум-дизайн для портала
  - R5: Нативное приложение + интернет-магазин
  - R6: Облачный хостинг + высокая сложность
- **Механизм вывода** — функция `evaluate()`, реализующая прямую цепочку рассуждений

### app.py

Веб-интерфейс с пошаговым опросником. Результат включает итоговую стоимость, сроки, детализацию расчёта и объяснение сработавших правил.

## Пример работы

1. Выберите тип проекта → CRM-система
2. Уровень дизайна → Индивидуальный
3. Объём → 16-40 страниц
4. Сложность → Enterprise, мобильная версия → PWA
5. Интеграции → ERP/1С + REST API + Аналитика
6. Хостинг → Облако (Yandex Cloud)

Результат: стоимость ~2 500 000 руб., срок ~200 дней, команда: 3+ backend + 2 frontend + DevOps + 2 QA + PM + аналитик.
